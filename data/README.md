# Dataset

## Phishing Websites

Source: UCI Machine Learning Repository

Dataset ID: 327

URL: https://archive.ics.uci.edu/dataset/327/phishing+websites

The dataset contains 11,055 instances and 30 features for binary classification of phishing and legitimate websites.

Target variable:
- `-1` = Phishing
- `1` = Legitimate

The dataset contains no missing values.

Citation:

Mohammad, R., & McCluskey, L. (2012). Phishing Websites. UCI Machine Learning Repository. https://doi.org/10.24432/C51W2X
